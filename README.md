# ⚽ Simulador de Partido de Fútbol (React + Vite)

Este es un proyecto personal que desarrollé para poner en práctica lo aprendido en **React**, repasar **JavaScript moderno** y experimentar con **GSAP** para agregar animaciones. El objetivo es simular partidos de fútbol minuto a minuto, generando jugadas progresivas con una narrativa tipo transmisión deportiva.

---

## 🔗 Demo en vivo

👉 [https://football-game-murex.vercel.app/](https://football-game-murex.vercel.app/)

---

## 🎯 Objetivo del proyecto

- Practicar conceptos clave de React (estructura, componentes, estado).
- Aplicar JavaScript con lógica organizada y progresiva.
- Utilizar **GSAP** para animaciones en el **scoreboard** y en la **lista de eventos**.
- Simular un partido con secuencia de jugadas, marcador y tiempo real.
- Mostrar **estadísticas del partido** al final de cada tiempo.
